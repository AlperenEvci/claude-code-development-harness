# Changelog

## 0.1.0 — 2026-08-27

- Initial public plugin structure.
- Added `/development-harness:setup` guided, conflict-aware installer workflow.
- Added `/development-harness:audit` read-only harness audit workflow.
- Added deterministic repository inspection, harness rendering, package validation, and installed-harness checks.
- Added Lite, Standard, and Fleet templates for Claude Code + Codex projects.
- Added project-specific path rules, workflow skills, and read-only domain researcher generation.
- Added strict profile validation for network, hook, commit, risk, model, and custom-component boundaries.
- Added negative tests preventing custom skills from pre-approving tools or custom agents from widening permissions.
